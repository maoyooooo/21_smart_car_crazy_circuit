## 项目概览

本项目采用**AURIX TC264**微控制器作为主控平台，实现了一套完整的智能车自动寻迹系统。系统融合了视觉图像处理、实时电机控制和传感器数据融合技术，能够在复杂赛道中自主导航和智能决策。

## 核心功能

### 1. 视觉识别系统 (`image_process`)
- **直线识别**：检测和跟踪赛道中的直线路段
- **十字识别**：识别十字交叉点并进行路径规划
- **拐弯识别**：准确检测并处理赛道的弯道转向
- **图像处理**：支持二值化、边缘检测等图像算法

### 2. 电机闭环控制系统 (`motor`, `Motor_encoder`)
- **精确的电机速度闭环控制**系统
- **编码器反馈**：通过编码器获取实时转速和位置信息
- **实时调速与转向控制**：支持动态速度和方向控制
- **轨迹追踪**：确保车辆稳定跟踪预设轨迹

### 3. 传感器融合模块 (`kalman`)
>该功能尚未实际上线，敬请期待
- **Kalman滤波**：采用卡尔曼滤波算法优化传感器数据
- **航向角估计**：高精度的方向角计算和滤波
- **数据融合**：多传感器数据的最优融合处理
- **姿态估计**：为导航系统提供可靠的姿态信息

### 4. 导航系统 (`navigation`)
>该功能尚未实际上线，敬请期待
- **路径规划**：基于赛道元素的智能路径规划
- **决策制御**：在十字、拐弯等关键点的智能决策
- **状态管理**：车辆运行状态的实时管理和切换

### 5. 数据存储 (`flash`)
>该功能尚未实际上线，敬请期待
- **参数存储**：存储PID参数、阈值等配置数据
- **断电保存**：确保关键参数在掉电后维持不变

### 6. 惯性导航系统（规划中）
>该功能尚未实际上线，敬请期待
- 预计集成IMU传感器数据
- 实现基于惯性测量的自主导航功能

## 项目架构

### 目录结构
```
├── code/                         # 核心功能模块
│   ├── image_process.c/h        # 图像处理算法
│   ├── motor.c/h                # 电机控制驱动
│   ├── Motor_encoder.c/h        # 编码器反馈模块
│   ├── kalman.c/h               # Kalman滤波器
│   ├── navigation.c/h           # 导航与决策模块
│   └── flash.c/h                # Flash存储管理
├── user/                         # 用户程序入口
│   ├── cpu0_main.c              # CPU0主程序（图像识别）
│   ├── cpu1_main.c              # CPU1主程序（电机控制）
│   └── isr.c/h                  # 中断服务例程配置
├── libraries/                    # Infineon底层库
└── Lcf_Tasking_Tricore_Tc.lsl  # 链接脚本配置
```

### 多核处理架构
- **CPU0**：主控制核心，处理图像识别、决策规划
- **CPU1**：专用电机控制核心，确保控制实时性
- **实时中断处理**：高频中断在ISR模块统一配置管理
