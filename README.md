# 第21届全国大学生智能汽车竞赛 - 疯狂电路组

本项目是第21届全国大学生智能汽车竞赛——疯狂电路组别的备赛代码库，采用 AURIX TC264D 平台实现视觉识别、多电机控制、姿态解算和自主导航功能。

## 硬件配置

- **主控微控制器**：Infineon AURIX TC264D 核心板
- **视觉传感器**：逐飞科技 MT9V03X 总钻风摄像头
- **姿态传感器**：IMU660RB 陀螺仪
- **测速反馈**：高精度电机编码器

## 软件架构与当前进展

本项目基于 **逐飞科技开源库 (SeekFree OpenSource Library)** 搭建。目前已跑通基础的软硬件协同，并实现了以下核心功能与控制闭环：

### 1. 图像与视觉处理 (`image_process`)
- **动态图像二值化**：摒弃固定阈值，引入 **OTSU 大津法** 根据灰度直方图自动计算并动态更新二值化阈值，显著提升在复杂光照（阴影、反光等）下的抗干扰能力。
- **高精度边线提取与拟合**：基于连续白块提取优化了多边线扫描逻辑，支持十字、分支等特殊赛道的防丢线处理；采用 **最小二乘法（线性回归）** 拟合中线斜率，极大程度消除了噪点引起的抖动和弯道误判。
- **路径状态机输出**：实时识别并输出当前赛道类型（直道、弯道、分支等）至全局状态变量，无缝供 CPU1 的电机控制系统进行状态切换，且在双核数据交互中具备严格的全局中断保护。

### 2. 运动控制系统 (`motor`, `Motor_encoder`, `navigation`)
- **双 PD 转向控制**：
  - **图像偏差 PD**：基于摄像头提取的赛道中线偏差进行前馈控制。
  - **陀螺仪角速度 PD**：引入 IMU660RB 陀螺仪的角速度反馈进行姿态修正，极大增强了车辆在高速转向时的动态稳定性。
- **速度 PID 闭环**：结合编码器数据反馈，实现了精确的电机速度 PID 闭环与差速控制。

### 3. 算法探索与优化
- **预瞄控制算法**：新加入了预瞄控制算法（Pure Pursuit / Preview Control），目前正处于实车测试验证阶段，以期进一步提升高速巡航的丝滑度。

## 硬件与通信特别说明

- **总钻风摄像头通信方案调整**：
  - 早期为屏蔽摄像头内置的 51 单片机曾尝试软硬件串口改造通信，但因该方案无法有效连接上位机调试，目前**已弃用模拟串口方案**。
  - **当前方案**：已恢复采用原 SCCB 并口通信方式，并在 IPS200 屏幕上完成了图像和边线的显示。针对恢复该方案后出现的固定阈值二值化效果不佳问题，已通过引入动态二值化算法（OTSU）加以解决。

## 工程目录结构

```text
├── code/                         # 核心功能模块
│   ├── image_process.c/h         # 图像处理算法 (二值化、边界扫描等)
│   ├── motor.c/h                 # 电机控制驱动 (速度 PID 闭环)
│   ├── Motor_encoder.c/h         # 编码器反馈模块
│   ├── kalman.c/h                # 姿态解算/卡尔曼滤波器
│   ├── navigation.c/h            # 导航与决策模块 (双 PD 转向控制等)
│   └── flash.c/h                 # Flash 存储管理
├── user/                         # 用户程序入口
│   ├── cpu0_main.c               # CPU0 主程序 (图像识别、控制逻辑主循环)
│   ├── cpu1_main.c               # CPU1 主程序 (传感器读取、控制处理等)
│   └── isr.c/h                   # 中断服务例程配置
├── libraries/                    # 逐飞科技开源底层库与外设驱动
└── Lcf_Tasking_Tricore_Tc.lsl    # 链接脚本配置
```

## 技术特点

- **多核协同处理**：充分发挥 TC264 的双核性能，合理分配图像识别（CPU0）与底层电机控制（CPU1）的算力，确保控制系统的高实时性。
- **多传感器融合控制**：将视觉传感器（摄像头）的前馈预测与惯性传感器（陀螺仪）的反馈修正相融合，极大提高了系统的鲁棒性。

## 开发与编译环境

- **IDE开发环境**：AURIX Development Studio (v1.10.2)
- **编译器**：Tasking TriCore Compiler
- **构建方式**：在 AURIX Studio 中直接打开本项目（即工作空间下的 `21_smart_car_crazy_circuit` 目录），点击 Build 即可编译烧录。
